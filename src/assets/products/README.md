# Product photos

Drop an image here named after the product **id** and it shows up automatically — no code
changes needed. Supported: `.jpg .jpeg .png .webp .avif`. Square-ish images look best
(they're shown in a rounded square, `object-cover`).

Example: `differin-adapalene.jpg`

Until a file exists for a product, the app shows a clean brand-monogram tile instead, so
nothing breaks if you only add a few.

> Prefer URLs? Set `image: 'https://…'` on a product in `src/data/mockCatalog.ts` instead —
> that takes priority over a file here.
